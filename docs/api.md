# API

- **Interactive docs:** `http://localhost:8000/docs` (Swagger UI) and `/redoc`.
- **Schema:** [`docs/api/openapi.json`](api/openapi.json). It is generated by
  `scripts/export_openapi.py`, and CI fails if it is stale.

## Conventions

| Topic | Behaviour |
|---|---|
| Auth | `Authorization: Bearer ar_<prefix>_<secret>` or `X-API-Key: …`. Create keys with `adaptiveroute create-api-key --name <who> --role admin\|user` or `POST /v1/admin/api-keys`. |
| Roles | `user`: own queries only. `admin`: all queries, API-key management, benchmark runs. |
| Rate limit | Per key, token bucket (default 60/min, burst 20; per-key override). Every response carries `X-RateLimit-Limit` / `X-RateLimit-Remaining`; a 429 carries `Retry-After`. |
| Idempotency | `POST /v1/queries` accepts `Idempotency-Key` (1–128 chars). A retry with the same key and body replays the stored response with `Idempotent-Replayed: true`. The same key with a different body returns 422. If the first request is still running you get 409. Keys expire after 24 h. |
| Errors | RFC 9457 `application/problem+json`: `{type, title, status, detail, instance, request_id, …}` |
| Tracing | Every response has `X-Request-ID`; send your own (8–64 safe chars) to correlate. |
| Pagination | Keyset: `GET /v1/queries?limit=20&before=<next_cursor>` |

## Endpoints

| Method & path | Purpose |
|---|---|
| `POST /v1/queries` | Route a query and (by default) execute it. Body: `query`, `strategy?`, `mode: sync\|async`, `execute`, `use_cache`. Sync returns 200; async returns 202 (`status=queued`). |
| `GET /v1/queries` | Recent queries (summaries). |
| `GET /v1/queries/{id}` | Full record: decision (all candidates + per-term scores), executions, answer, cost, trace links. |
| `POST /v1/queries/{id}/feedback` | `{success, comment?}` labels the final execution. This is the adaptive router's learning signal. |
| `POST /v1/route/compare` | Runs every strategy on one query and returns each decision (no execution). |
| `GET /v1/agents` | Agents with live stats (from `agent_stats`) and in-flight load. |
| `GET /v1/strategies` | Strategies, availability and the active adaptive configuration. |
| `GET /v1/benchmarks`, `GET /v1/benchmarks/{id}` | Benchmark reports. |
| `POST /v1/benchmarks` (admin) | Re-run the replay benchmark on the worker; returns 202. |
| `GET /v1/traces/{trace_id}` | The trace's spans (proxied from Jaeger) for the dashboard waterfall. |
| `POST/GET/DELETE /v1/admin/api-keys` (admin) | Create (key shown once), list, revoke. |
| `GET /healthz` | Liveness: no dependency checks. |
| `GET /readyz` | Readiness: Postgres + Redis (503 when not ready). |
| `GET /metrics` | Prometheus exposition. |

## Examples

```bash
KEY=$(docker compose exec -T api adaptiveroute create-api-key --name me --role admin | tail -1)

# Route + execute synchronously with the adaptive router
curl -s localhost:8000/v1/queries \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{"query": "Which three customers spent the most in 2024?", "strategy": "adaptive"}'
```

Response shape (abridged; `…` marks values that vary per run):

```json
{
  "id": "…",
  "status": "completed",
  "decision": {
    "strategy": "adaptive",
    "agent": "sql",
    "reasoning": "'sql' scored 0.671: semantic fit 1.00 (cos 0.749), est. success 0.70 from 0.0 similar past queries, ~2.5s, ~$0.00040, load 0%. Runner-up …",
    "latency_ms": "…",
    "candidates": [
      {"agent": "sql", "score": 0.671, "components": {"similarity": 0.749, "semantic": 1.0, "success": 0.7, "contrib_semantic": 0.45, "contrib_success": 0.245, "contrib_latency": "…", "contrib_cost": "…", "contrib_load": 0.0}}
    ]
  },
  "executions": [{"attempt_no": 1, "agent": "sql", "status": "success", "latency_ms": "…", "input_tokens": "…", "output_tokens": "…", "cost_usd": "…", "cache_hit": false}],
  "answer": "```sql\nSELECT …\n```",
  "total_cost_usd": "…",
  "links": {"self": "/v1/queries/…", "trace": "/v1/traces/…"}
}
```

The decision values above come from a real local run with an empty history: estimated
success equals the 0.7 prior because there were 0 similar past queries.

```bash
# Tell the router whether it worked (the adaptive router learns from this)
curl -s localhost:8000/v1/queries/$ID/feedback -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" -d '{"success": true}'

# Async: returns 202 immediately; poll the self link
curl -s localhost:8000/v1/queries -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" -d '{"query": "Prove that sqrt(2) is irrational", "mode": "async"}'

# Compare all strategies on one query
curl -s localhost:8000/v1/route/compare -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" -d '{"query": "What is the time complexity of quicksort?"}'
```
